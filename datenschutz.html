Datenschutzerklärung – Alfred

Alfred ist eine private Anwendung, die ausschließlich von ihrem Inhaber für die eigenen Konten genutzt wird.

Welche Daten werden verarbeitet?

  • Google Kalender: Termine lesen und anlegen.
  • Google Aufgaben: Aufgaben lesen und anlegen.
  • Gmail: E-Mails lesen und Entwürfe erstellen.

Wofür?

Die Daten werden nur genutzt, um dem Inhaber Termine, Aufgaben und E-Mails zusammenzufassen und Entwürfe vorzubereiten. Es werden keine Daten verkauft, an Dritte weitergegeben oder für Werbung verwendet.

Speicherung

Zugangsschlüssel werden nur auf dem privaten Rechner des Inhabers gespeichert. Zur Beantwortung von Anfragen werden Inhalte an den KI-Dienst Claude (Anthropic) übermittelt.

Google-API-Richtlinie

Die Nutzung und Weitergabe von Informationen, die über Google-APIs empfangen werden, erfolgt gemäß der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
